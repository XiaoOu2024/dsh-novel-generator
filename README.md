# 小说工坊 · dsh-novel-studio

DSH 的常驻插件：在可拖动的时间线上写小说。每个作品绑定一个普通会话，章节正文与世界快照都由那个会话里自己的 Agent 生成。

## 打开方式

界面左下角（设置按钮旁）的 **小说工坊** 按钮，点开就是项目管理界面；右上角「关闭」退出。

## 界面流程

1. **作品列表**：创建 / 删除 / 打开作品。创建时选工作目录、模型、预设——创建动作本身会调用 `sessionController.create` 为作品开一个会话，会话照常出现在左侧列表里，可以直接进去对话。
2. **时间长河**（作品主界面）：最上方是时间线，单位可选 30 / 90 / 365 天每格；拖动时下方世界观、角色列表、势力列表、关系（`甲 乙 关系`）随之切换为该时间点之前最新的一份世界快照。右上角是「进入故事」，进入离选中时间最近的章节。
3. **章节故事**：左上角「← 时间长河」回到时间线界面；右上角「章节大纲 →」把故事页向左收起、翻开大纲页。正文可直接编辑，底部「保存」。
4. **章节大纲**：左上角「← 章节故事」。可填章节标题、故事时间长度（天）、章节最低/最多字数、梗概最低字数与故事梗概。梗概达到最低字数且其他项填完才能「保存」；保存后「生成章节故事」才可点，生成成功会弹提示；不满意可以改大纲保存后重新生成。右上角「自动推演」按最新世界快照与最近一章的梗概给出本章梗概、时间长度与标题。

## 世界快照怎么来

- 每部作品有一条以「天」为单位的时间线（0 = 创建作品那天）。
- 章节生成成功后，如果本章结束时间距上一份快照已达到一个时间线单位，Host 会自动排一个快照任务：让作品会话阅读这段时间内的章节，产出新的世界观 / 角色 / 势力 / 关系，写进作品数据。
- 世界界面右上角的「同步世界快照」可以手动触发同一件事。

## 数据与接口

- 数据目录：`<DSH_HOME>/novel-studio/projects/<项目id>/project.json`（`DSH_HOME` 缺省为 `~/.dsh`）。可用插件行的 `dataDir` 配置覆盖。
- HTTP 接口前缀：`/dsh-novel-studio/api`，只接受本机页面同源请求。
- 生成与推演都是异步任务：`POST /generate`、`POST /deduce`、`POST /snapshot/refresh` 返回 `jobId`，再由 `GET /job?id=` 轮询。

## 自检脚本（开发用，不随包发布）

```bash
node selfcheck.mjs <临时工作目录>          # 创建/时间线/章节/大纲/保存/删除
node selfcheck-generate.mjs <临时工作目录> # 真实调用模型生成一章
node selfcheck-snapshot.mjs <临时工作目录> # 真实调用模型产出一份世界快照
```

脚本默认访问 `http://127.0.0.1:3080`，仅用于本机验证。
